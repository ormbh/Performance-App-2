[تقرير التحقق v121](Saytara-Verification-v121.md)

استخرج ملف ZIP كاملًا، ثم افتح `index.html` مع إبقاء مجلد `assets` بجواره، واختر ملف Excel التشغيلي.

تم تطبيق التصميم المعتمد على لوحة المشاريع وتقريرها والطباعة، بألوان التطبيق وخطوطه وشعار المجلس التنفيذي. يتكون العرض من ثلاثة صفوف بعمودين متساويين: الالتزامات والإنفاق مقابل التقدم حسب السنة والربع والشهر، ثم حالة المشاريع مقابل محافظ المديرين، ثم أعداد المشاريع حسب الأولوية والنوع مقابل الموازنة. يظهر جدول المتابعة بخمسة أعمدة بعرض الصفحة أسفلها. تتطابق بيانات اللوحة والتقرير ضمن التصفية نفسها، وتستند أسهم التغيّر إلى نسختين شهريتين مؤكدتين ومطابقة صالحة.

يعرض جدول الملاحظات البنود التي تستدعي المتابعة فقط: المشاريع المفتوحة المتأخرة، والمعلقة، والتي لم تبدأ، والمشاريع غير المكتملة ذات الملاحظات الأصلية المسجلة. لا تدخل الملاحظات التاريخية للمشاريع المنجزة أو القيم المالية العادية أو نقص البيانات وحده في هذا الجدول. أزيل عمود «سبب المتابعة» مع إبقاء الملاحظات الأصلية كاملة.

حُفظت معادلات القالب وشرط وجود اسم البند كما اختار المستخدم، وتصحيح التشريعات إلى 152 على الموعد و28 تجاوز الموعد، وملاحظة جهة الطلب في الطباعة. القالب المرفق يفتقد أسماء المشاريع والقيم المالية؛ لا تُستبدل ببيانات افتراضية. التفاصيل وحدود الاختبارات في تقرير التحقق.

اجتازت النسخة فحوص الحسابات والتصفية والمقارنة، والعرض على الحاسوب والجهاز اللوحي والهاتف، ومراجعة جميع صفحات الطباعة في ملفات الاختبار. ملف التطبيق لا يتضمن ملف Excel أو بيانات الاختبار. بصمات الملفات في `SHA256SUMS`.
