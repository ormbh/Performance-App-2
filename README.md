# Performance App v119

[تحميل التطبيق المحدّث v119](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v119.zip)

[تقرير التحقق v119](Saytara-Verification-v119.md)

استخرج ملف ZIP كاملًا، ثم افتح `index.html` مع إبقاء مجلد `assets` بجواره، واختر ملف Excel التشغيلي.

تم تحديث لوحة المشاريع بألوان وخطوط التقرير الشهري، وإضافة عرض الحالة والعدد والموازنة ومتوسط الإنجاز، والأولوية حسب النوع، والتقدم حسب السنة والربع والشهر، والالتزامات والإنفاق، وأولوية متابعة محافظ مديري المشاريع. أسهم التغيّر تعتمد نسختين شهريتين مؤكدتين ومطابقة صالحة. أزيل عمود «سبب المتابعة» مع إبقاء الملاحظات الأصلية كاملة.

حُفظت معادلات القالب وشرط وجود اسم البند كما اختار المستخدم، وتصحيح التشريعات إلى 152 على الموعد و28 تجاوز الموعد، وملاحظة جهة الطلب في الطباعة. القالب المرفق يفتقد أسماء المشاريع والقيم المالية؛ لا تُستبدل ببيانات افتراضية. التفاصيل وحدود الاختبارات في تقرير التحقق.

ملف التطبيق لا يتضمن نسخة من ملف Excel أو بيانات الاختبار. بصمات الملفات في `SHA256SUMS`.
