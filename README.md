The approved paper rules are implemented: **A4 landscape for agenda, council and HH reports; A4 portrait for all remaining browser-print views, including the project report. No A3.** Stored A3 preferences normalize to A4. Print retains 10mm margins and its independent readable scale: table content/names/notes/in-table statuses 12pt Dubai Regular; headings 13.5pt Dubai Bold. Cards and rows stay together when they fit; oversized content continues naturally. The first header contains only the official logo and report title with the source cutoff. Later pages have no masthead; table headings repeat. Footers contain only copyright and page X of Y. Entity filters are hidden while selected scope still determines the exported records.

Monthly short value/status labels and strategy metric names now use **15px Dubai Regular Ink**. Agenda category labels and special subgroup names remain 18px; screen table/badge text 16px and headings 18px Bold. The generated legislation labels are **SLC منجز ضمن موعد** and **SLC منجز بعد موعد**. The repeated SLC comparison paragraph is removed on screen and in print; source fields and timing calculations remain.

The compliance audit also corrected primary/filter/disabled states, export loading indication, native chart status fills and figure fonts, HH progress-ring/summary geometry, wrapped checks badges, mobile regular table text, task-page print cleanup and comparison/table pagination. Approved search spacing, Search/current-page navigation, all three reports in every loaded-page menu, neutral source names, Ink/Taupe text roles, removed title subtitles and solid financial bars remain. The separate entity-dashboard redesign is still a concept.

Desktop/mobile and native PDF gates pass. An independent visual/font/geometry review checked **24 PDF cases / 394 pages** without clipping or footer overlaps. All 672 illustrative records, calculations, scopes and 34 protected assets match the immutable v133 release. The complete package is checked against its manifest and tested from a fresh extraction, including actual upload, search/details, menu links, narrow HH layout and portrait/landscape PDFs. Source workbooks and generated QA records are excluded.

Extract the complete ZIP and open index.html with assets beside it. Select your own workbook; processing stays on your device. Retain the previous folder until your browser notes/settings are checked. Readable sources, local fonts, standard, verification and integrity manifest are bundled.

Validation uses frozen illustrative workbooks, not the operational workbook from earlier screenshots. Native Windows Chrome, physical printing and native Office editing were not tested. Browser/PDF checks do not constitute formal accessibility certification. Disable the browser's own headers/footers when printing to retain the approved footer.
