**تنزيل PDF** replaces the app's Print buttons. It downloads locally without opening a print dialog or using an internet service. The complete ZIP includes the native PDF engine, Arabic shaping, approved TEC font bytes and official logo. Text stays selectable and charts stay vector.

Monthly reports default to one continuous 297mm-wide page with the approved 281mm content width, Linen surface, 8mm top/side insets and 16mm bottom reserve. **إعدادات PDF** retains the monthly A4 portrait option. Agenda, council and HH reports use A4 landscape; all other report views use A4 portrait. Headers show the official logo and title/date once; footers show only copyright and real page numbers.

Actual-button verification passes 307 checks across ten cases/165 PDF pages, with 54 additional robustness checks and 143 checks of the final extracted ZIP. Independent review confirms source names/values, Arabic fonts, chart colors, rows, headings and footer spacing. Cold download, repeated-action guards and missing-component recovery pass. Original models, all 65 source stylesheets, protected assets and Office export templates remain unchanged. The native print timing defect that produced temporary 80mm pages is reproduced and corrected.

The preview uses illustrative data; no operational workbook was supplied or published.
