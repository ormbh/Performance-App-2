# Performance App v123

[تحميل التطبيق المحدّث v123](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v123.zip) · [تقرير التحقق](Saytara-Verification-v123.md)

تم تطبيق تصميم TEC Apple-Inspired المعتمد على اللوحة الشهرية، ومحفظة المشاريع وتقريرها والطباعة، وصفحات البحث ورفع ملف التقرير. تحافظ النسخة على شعار المجلس التنفيذي وخطوط TEC وألوانها، مع خلفية دافئة وبطاقات هادئة وعناصر تحكم متسقة.

- أسماء البنود في جدولي المتابعة بلون نص محايد ووزن عادي، دون تلوين أو خط عريض.
- ترتيب المتابعة: **متأخر ← مجمّد ← ملغى ← منقول**. تشمل مشاريع المتابعة المشاريع غير المنجزة التي تجاوزت موعدًا صالحًا، والمجمّدة والملغاة والمنقولة، حتى دون ملاحظات؛ لا تكفي الملاحظة وحدها لإدراج المشروع.
- المتأخر أحمر دائمًا، والمنجز أخضر، بما فيه التشريع المنجز بعد الموعد. تبقى الحالة مكتوبة بجانب اللون، ونسب وأشرطة الإنجاز وأسهم التغيّر ↑/↓ عند وجود مقارنة صالحة.
- الاستراتيجية في عمود المتابعة التنفيذية أسفل التشريعات. تظهر «الأجندة المعتمدة» و«المواضيع المستجدة» و«الموازنة المعتمدة»، وتعريف SLC مرة واحدة أسفل التشريعات.
- المشاريع في ثلاثة صفوف بعمودين: الالتزامات والإنفاق يمينًا مقابل التقدم الزمني يسارًا؛ الحالة مقابل محافظ المديرين؛ العدد حسب الأولوية والنوع مقابل الموازنة؛ ثم جدول المتابعة بعرض الصفحة.
- تُخفى الفئات الفارغة أو غير المصنفة في رسوم الحالة وH/M/L مع بقاء سجلاتها في الإجماليات ومراجعة المصدر. لا تُكرر مفاتيح الرسم عندما تعرّفها التسميات المباشرة.
- البحث يحافظ على الاقتراحات والتصفية والترتيب والتصدير والتنقل بلوحة المفاتيح. رفع الملف يحافظ على القراءة المحلية والسحب والإفلات واستعادة الملف الحالي بعد الخطأ.

استخرج ملف ZIP كاملًا، ثم افتح `index.html` مع إبقاء مجلد `assets` بجواره، واختر ملف Excel التشغيلي. تُقرأ البيانات على جهازك ولا تُرسل إلى خادم. تبقى إعدادات طباعة المشاريع A4/A3 أفقيًا مع تباعد مريح أو مضغوط، والطباعة الشهرية A4/A3.

حُفظت معادلات القالب وشرط وجود اسم المشروع كما اختار المستخدم، والقيم المالية والنسب وقواعد المطابقة. القالب المرفق يخلو من أسماء المشاريع والقيم المالية؛ إجمالي المشاريع المسماة القابلة للحساب هو صفر، ولا تُستبدل البيانات الناقصة ببيانات افتراضية. ملف التطبيق لا يتضمن ملف Excel أو أسماء أو أموال أو مقارنات توضيحية.

اجتازت النسخة مقارنة 56 نطاقًا حسابيًا، وفحوص حدود المتابعة والمقارنة والتفاعل والهاتف، ومراجعة جميع صفحات ستة ملفات طباعة. التفاصيل وحدود المتصفح والخطوط في تقرير التحقق، وبصمات التنزيل في `SHA256SUMS`.

[المعاينات السابقة التي سبقت التنفيذ](TEC-Apple-Status-Colors-Illustrations.md) تستخدم بيانات توضيحية؛ عدلت النسخة المنفذة أسماء الجدولين إلى نص محايد غير عريض حسب آخر طلب.
