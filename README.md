# Performance App v130

[Download the updated app — v130 ZIP](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v130.zip) · [Actual previews and before/after](v130-Previews/README.md) · [Verification report](Saytara-Verification-v130.md) · [Approved TEC design standard](Design-Standard/TEC-Apple-Inspired-Design-Standard-Revision-5.md)

The approved Revision 5 changes are applied to the app: typography, status badges, title-label removal, shared report headers, navigation, filters, menus, buttons, icons, screen footer and native printing. The Google-like search, six-column findings table and approved upload layout remain.

DIN Regular headings use 38/30/28px; DIN LT Regular figures use 34–40px. Table names, notes and statuses use Dubai Regular 16px; column headings use Dubai Bold 18px. Source names remain neutral and regular. Completed work is green, unfinished late work is red, and the other approved status colors are retained.

Report headers show the official logo, title and actual cutoff date only. Plain primary links and one application menu retain all destinations. Sector/unit/entity fields are separate from print actions; additional project fields use a disclosure. Outside click and Escape dismiss menus. Mobile filter sheets retain selections and keyboard focus. Clearing fields preserves the workbook, report date, comparison and saved display/print preferences.

Print uses the independently approved readable scale. The first page has one report title containing the actual date and official logo. There is no continuation report masthead. Each footer has only copyright and generated page X of Y. The entity filter field is omitted while its selected scope still applies. Table headings repeat and pagination follows the content.

**Use:** extract the complete ZIP, open `index.html` with its `assets` folder beside it, and choose the report workbook. Workbook processing stays on the device. Keep the prior folder until existing browser notes/settings are checked. Readable sources, the approved standard, verification report and file-integrity manifest are included.

Desktop, mobile, keyboard, upload, source-regression and native PDF checks passed. The final extracted package was exercised through a local HTTP origin; direct file navigation is blocked by the managed test browser, and native Windows opening/physical printing were not tested. Previews and numerical checks use clearly labelled illustrative data. No operational workbook or uploaded operational PDF is published.
