# Performance App

[Download the current app — v168](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v168.zip)

Extract the ZIP and open **index.html**. Keep **assets** and **manifest.webmanifest** beside it, then select your report workbook. No workbook is bundled.

The approved entity report is implemented: matching screen/PDF scope and content, separate recorded-status charts and follow-up alerts, consistent readable Arabic tables, complete notes and content-driven native pagination. Empty scopes and missing source names receive appropriate explanations. Unnamed special-project rows are excluded consistently.
