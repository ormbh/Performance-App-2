# Performance App v126

[تحميل التطبيق v126](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v126.zip) · [تقرير التحقق](Saytara-Verification-v126.md)

أصبحت بطاقات اللوحة الشهرية أكثر إحكامًا، مع وضع أسهم التغيير بجوار الإجماليات وتقليل الفراغات دون تصغير الخطوط. انخفض ارتفاع البطاقات الرئيسية للحاسوب بمقدار 52–88 بكسل في حالات التحقق.

عولج التمرير العمودي غير الضروري في مخططات الأولوية. تظهر الأشرطة الملونة بالقيم الفعلية على المقياس المشترك نفسه، وتبقى تغطية بيانات الموازنة الناقصة واضحة. يُسمح لبطاقة مالية طويلة بالاستمرار عبر صفحات A4 للمشاريع لمنع صفحة افتتاحية تحتوي على العنوان فقط، مع الحفاظ على ترابط كل قسم مالي.

اجتازت التعديلات مراجعة فعلية ومستقلة للتصميم والعرض المتجاوب والطباعة. جميع ملفات JavaScript الـ51 ووحدات الحساب الـ15 والخطوط والشعار وألوان TEC دون تغيير عن v125. بقي المتأخر أحمر والمنجز أخضر، واستراتيجية الأمانة العامة أسفل التشريعات. يحتفظ الإصدار بإصلاحات التباين وتصميم البحث ورفع الملف المعتمد. [قواعد التصميم](DESIGN-CONTRACT-v124.md).

استخرج ZIP كاملًا، ثم افتح `index.html` مع إبقاء مجلد `assets` بجواره واختر ملف Excel التشغيلي. تُقرأ البيانات على جهازك ولا تُرسل إلى خادم.

القالب المرفق يخلو من أسماء البنود التشغيلية؛ حُفظ شرط وجود الاسم ومعادلات القالب كما اختار المستخدم. ملف التشغيل الظاهر في الصور لم يُرفع، لذلك تبقى أرقامه غير متحققة من المصدر. لم يُختبر Windows أو قارئ الشاشة؛ حدود التحقق والأدلة موضحة في التقرير. بصمات التنزيل في `SHA256SUMS`.
