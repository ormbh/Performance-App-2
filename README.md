# Performance App

[Download the current app — v167](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v167.zip)

Extract the ZIP and open **index.html**. Keep **assets** and **manifest.webmanifest** beside it, then select your report workbook. No workbook is bundled.

The approved project portfolio is implemented: consistent summaries, count-scaled deadline charts, compact status definitions, shared tables, scoped links and matching native A4 output. Financial parsing is consistent, while recorded progress, project completion and spending remain separate measures.
