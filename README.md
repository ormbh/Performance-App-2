# Performance App v122

[تحميل التطبيق المحدّث v122](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v122.zip)

[تقرير التحقق v122](Saytara-Verification-v122.md)

استخرج ملف ZIP كاملًا، ثم افتح `index.html` مع إبقاء مجلد `assets` بجواره، واختر ملف Excel التشغيلي.

تُطبّق تحسينات مراجعة لوحة المشاريع على اللوحة وتقرير المشاريع والطباعة، مع الحفاظ على التصميم المعتمد: ثلاثة صفوف بعمودين متساويين ثم جدول متابعة بخمسة أعمدة بعرض الصفحة. تبقى ألوان التطبيق وخطوطه وشعار المجلس التنفيذي.

- ملخص للمحفظة ضمن التصفية الحالية، وأرقام إجمالية أوضح، وتفاصيل قابلة للفتح.
- ألوان تغيّر بحسب معنى المؤشر؛ تغيّر الأموال والأعداد العامة محايد، وزيادة الإنجاز أو انخفاض المتابعة إيجابي.
- عرض الصفر المسجل صراحةً، وشرح غياب أسماء المشاريع مع الانتقال لمراجعة المصدر، وإعادة ضبط التصفية عند عدم وجود نتائج مطابقة.
- جدول «المشاريع التي تتطلب المتابعة» بمعايير واضحة وملاحظات أصلية كاملة؛ صفوفه بطاقات مع عناوين الحقول على الهاتف، مع أزرار أكبر وتلميحات تمرير للجداول العريضة.
- توضيح مقاييس العدد والموازنة، ومتوسط الإنجاز مقابل نسبة المشاريع المنجزة، وقيمة الأعمال مقابل الإنفاق حسب الفواتير.
- إعدادات طباعة المشاريع: A4 أو A3 أفقي، وتباعد مريح أو مضغوط، مع حفظ خيارات الجلسة وإبقاء الملاحظات والتعريفات كاملة، ومعالجة الصفحات الزائدة بسبب الملخص أو فقرة التعريفات.

تتطابق بيانات اللوحة والتقرير ضمن التصفية نفسها. حُفظت معادلات القالب وشرط وجود اسم البند كما اختار المستخدم، ومعايير جدول المتابعة، وتصحيح التشريعات إلى 152 على الموعد و28 تجاوز الموعد، وملاحظة جهة الطلب في الطباعة. أسهم التغيّر تتطلب نسختين مؤكدتين ومطابقة صالحة. لوحة التقرير الشهري وتعريفاتها لم تتغير.

القالب المرفق يخلو من أسماء المشاريع والقيم المالية؛ إجمالي المشاريع المسماة القابلة للحساب هو صفر، ولا تُستبدل البيانات الناقصة بقيم افتراضية. ملف التطبيق لا يتضمن ملف Excel أو بيانات الاختبار. اجتازت النسخة فحوص الحسابات والتصفية والمقارنة واللوحة والتقرير والهاتف والطباعة؛ التفاصيل وحدود الاختبارات في تقرير التحقق، وبصمات الملفات في `SHA256SUMS`.
