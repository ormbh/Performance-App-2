# Performance App

[Download the current app — v162](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v162.zip)

Extract the ZIP and open **index.html**. Keep its **assets** folder and **manifest.webmanifest** beside it, then choose your report workbook. No workbook is bundled.

The special-project report now shows its title and overall total above the two charts. Repeated detail-card headings/numbers and the duplicate leadership yes/no field are removed. The leadership badge matches on screen and in PDF.

The ZIP contains only the app and a short start guide. [Documentation](docs/README.md) and [earlier releases](archive/README.md) are kept separately.
