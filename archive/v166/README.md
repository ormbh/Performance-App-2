# Performance App

[Download the current app — v166](https://github.com/ormbh/Performance-App-2/raw/refs/heads/main/Performance-App-v166.zip)

Extract the ZIP and open **index.html**. Keep **assets** and **manifest.webmanifest** beside it, then select your report workbook. No workbook is bundled.

The approved monthly designs and audit fixes are implemented: corrected leadership/TEC grouping, separate unknown statuses, counted status bars, consistent colors, compact legend, scoped report links and matching screen/PDF figures. The approved legislation layout retains late within work in progress.
