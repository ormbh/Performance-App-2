# Agenda empty-category behavior — v150

Approved 13 October 2026. Extends the v149 agenda rules.

- Show a chart category only when it contains at least one record in the selected scope. Hide its title/count box and whole matrix when it has no records.
- If exactly one category remains, its title/count box and matrix use the available chart width. Apply the same behavior to screen and native PDF.
- If the entire scope is empty, retain the existing empty-state message without category boxes or matrices.
- Keep source eligibility, counts, denominators, record keys, common bar scaling, status/quarter ordering, colors and within-category zero dashes unchanged.
- Retain all v149 cover, footer numbering and table corrections.
