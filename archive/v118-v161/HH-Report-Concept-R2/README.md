## Interactive offline concept

Extract the full folder and open **index.html**. All fonts, images and illustrative records are bundled locally. Try sector, unit, entity and requester filters, first-selected **+N** labels, list search, pagination and record details. The requester filter uses the approved leadership/TEC classification, including blanks in TEC. Other app pages in the menu are inactive in this isolated concept.

The PDF button downloads the prepared, unrestricted review PDF. It does not regenerate a filtered report. The PDF contains a cover, the paired charts and legend on one content page, then a sample card and design-rule examples. It is not a complete 62-record report export.

## Meaning and review limits

The source remains the same illustrative workbook, reference date **30/09/2026**, with original values preserved. The displayed date is report metadata rather than an automatic project-date filter. The latest cohort rule affects classification only: the two formerly unassigned requester records are included in TEC.

HH has no approved explanatory legend prose in the current source. The detailed legend wording is proposed for review and follows recorded HH statuses; it does not import agenda-specific approval definitions. The app and its shared components have not yet been changed.
