# Approved agenda design — v146

Approved 13 October 2026. This agenda page/PDF extension takes precedence over the generic first-header rule in DESIGN-STANDARD.md; other pages retain Revision 20.

- Preserve the original status-row / quarter-column matrix, aligned status heading, source order, effective periods, common count scale and distinct approved/emerging cohorts. Keep source records and definitions unchanged.
- Show true zero counts as **–**, preserving numeric zero in the data and accessible **صفر**. The chart scale still starts at numeric zero.
- Color only completed/late status names: Green **#01831E**, Red **#C00000**. Other status names use Ink **#4F4E4E**. Bar and legend swatches retain their approved mappings. This does not change shared record badges.
- Keep the shared legend with readable names. Omit status percentages and repeated bottom-left grand totals. Retain headline, quarter and status totals.
- Hide a status/quarter only when absent throughout the selected chart scope. Keep shared rows/columns in both cohorts and show dashes at zero intersections. Empty scopes show an empty-state message. Preserve source undated groups.
- Use TEC/Dubai/DIN typography and shared 48/32/16px page gutters. Keep Arabic text, source labels and keyboard-accessible filter controls. Show first-selected +N or الكل in filter summaries; display a partial entity selection beneath the title.
- Agenda PDF: A4 landscape 297 × 210mm;10mm margins; copyright/page footer only. First page: title, selected entity if applicable, reporting month range, both chart matrices together. No repeated masthead on continuation pages; repeat table column headings.
- Default month range is January through the report-date month/year, preserving the existing editable period override. It changes display text only, not record eligibility or cutoff calculations.
- Widen topic/entity columns; move the narrow deadline/quarter column after them. Preserve literal source content. Remove the agenda source-notes appendix and its links from page/PDF.
- Retain approved font sizes in export. For unusually long first-page metadata, reduce vertical spacing only when measured overflow requires it; do not clip content or silently shrink fonts. Long record rows continue without omitting text.
