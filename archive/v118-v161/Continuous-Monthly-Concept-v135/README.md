# Continuous monthly report — preview

[View the one-page PDF](ILLUSTRATIVE-Continuous-Monthly-Preview.pdf) · [Download the preview ZIP](Continuous-Monthly-Preview.zip) · [View the full report image](Continuous-Monthly-Preview.png)

This preview uses the same frozen illustrative workbook as the released v135 monthly print example. It is not the user's operational report. The app and design standard have not been changed for this preview.

| Element | A4 example | Continuous concept |
| --- | --- | --- |
| Output | 3 A4 portrait pages | 1 custom-height PDF page |
| Width | 210 mm | 210 mm |
| Height | 297 mm per sheet | 634 mm for this example |
| Content | Paired portfolios and full-width followups | Same content in an uninterrupted flow |
| Fonts and figures | Approved v135 print roles | Same fonts, sizes, values and eight followup row keys |
| Header | First page only | Once at the top |
| Footer | Copyright and page count | Copyright and page 1 of 1 at the bottom |

The height follows the selected content; 634 mm is this example's measured height. Projects remain physically left and executive portfolios right. This is a native text/vector PDF, not a screenshot-based PDF.

Continuous PDF is intended for digital scrolling and zoom. Physical A4 printing still needs the normal paginated A4 export; printing this tall page with a fit-to-sheet option would shrink it.
