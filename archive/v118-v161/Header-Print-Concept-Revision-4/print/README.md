# TEC print concept — Revision 4

This is a review specimen using the same eight frozen illustrative records as Revision 3. It is not an export of the uploaded operational report, and its three pages do not predict the page count of a full report.

The latest user clarification supersedes the earlier notes instruction. The first printed header contains only the official logo and this title:

**التقرير الشهري للأداء والتنفيذ - لتاريخ 30/09/2026**

There is no organisation note above it, no separate date/scope note below it, and no specimen commentary beside the report masthead.

| Part | Revision 4 concept | Retained typography |
|---|---|---|
| First-page header | Report title with the date within the title; official logo | DIN Next Arabic Regular, 24pt; logo 38mm wide with preserved proportions |
| Later pages | No repeated report title, logo, date or scope; section and table column headings remain | Section DIN Regular 16pt; table header Dubai Bold 13.5pt |
| Footer | Exact copyright line and `صفحة X من Y` only | Dubai Regular, 10.5pt, Ink #4F4E4E |
| Table | Same eight illustrative records, source order, regular neutral names and approved status badges | Dubai Regular, 13.5pt, 1.6 line spacing |
| Paper | A4 landscape; 10mm external margins; content and footer stay within the usable page | No type shrinking to force a fixed full-report page count |

Source-history caveats and the SLC explanation stay in the relevant report body. Footer simplification does not remove these data explanations.
