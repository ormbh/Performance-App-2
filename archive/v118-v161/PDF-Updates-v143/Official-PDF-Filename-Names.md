# Monthly PDF filename names

Official English names supplied by the user on 13 October 2026. The same user requested omitting **Department** and **Section** from filenames. Keep **Office** and **Sector** where supplied. The General Secretariat name has no Sector suffix. This mapping affects filenames only; Arabic report captions and source values remain intact.

Format: **TEC_Monthly_Mmm_yy[_scope].pdf**. Use the report date, first selected partial unit before a partial sector, and no additional-selection count. Full/unrestricted scope is omitted.

Spaces and punctuation become underscores; **&** becomes **and**. Match the app’s existing short Arabic names, the full Arabic names below and the existing bounded legacy aliases. Official English source names are also supported. Unknown Arabic names use **Selected_Unit** or **Selected_Sector** until mapped; never silently represent a selected scope as all. Other printable ASCII source names retain their supplied words after sanitization.
