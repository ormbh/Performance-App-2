# Approved agenda and menu update — v148

Approved 13 October 2026. These latest user instructions supersede the v146/v147 agenda placement and legend rules. Other approved TEC typography, data semantics, filter behavior and output profiles are retained.

- Agenda PDF: A4 landscape, 297 × 210mm, 10mm outer margins and a separate copyright/page-number footer.
- Page 1: original agenda cover photo and paired logos, report title, selected entity when applicable, and reporting month range/year. This metadata appears only on the cover.
- Page 2: both status-row/quarter-column charts followed by the complete **تعريفات مستويات الإنجاز** block. Keep the whole block together. Reduce internal whitespace only when additional status rows require it; preserve the approved type sizes. Reject exceptional overflow explicitly rather than clipping it.
- Remove the upper mini legend. Put each approved colored square beside its status name in the definitions below the chart. Preserve all five definitions and their exact wording.
- Positive completed chart values and status-row totals use Green **#01831E**; positive late values use Red **#C00000**. Zero dashes, quarter totals and overall totals remain neutral. Keep the existing source values, common count scale, bar colors and filtered visibility rules.
- Detail tables begin on page 3 when records exist. Restore visible cohort title (such as **الأجندة المعتمدة**), quarter and topic count above each group. Repeat column headings on continuation pages. Preserve full record content and source order.
- Original cover imagery is embedded in the offline bundle; PDF image rendering does not inherit transparency from preceding background shapes.
- Search landing-page menu sits on the physical right; logo, title and search input positions are retained. The dropdown remains inside phone viewports and keeps its existing keyboard behavior.
