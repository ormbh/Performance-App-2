# Direct offline PDF download — v138

The app replaces report Print buttons with **تنزيل PDF** and labels settings **إعدادات PDF**. Extract the complete app ZIP and open index.html; no export server or internet service is required. The bundled engine writes selectable Arabic text, embedded TEC font outlines and vector charts. The official logo retains its original image bytes.

Monthly defaults to one continuous 297mm-wide page, with the approved 281mm content width, Linen perimeter and reserved footer space. Monthly A4 portrait remains available in PDF settings. Agenda, council and HH use A4 landscape; other report views use A4 portrait. Source selections and full records remain effective.

The ten actual-button cases contain 165 pages, reviewed independently for source content, Arabic, native fonts/vectors, geometry and pagination. A further 54 robustness checks cover immediate first download, rapid actions, missing-component recovery, checks and projects reports. The final extracted ZIP passes 143 further checks of file hashes, actual upload, search/details, report menus and download controls. Fixtures and sample PDFs are excluded from the app ZIP. The operational workbook was not supplied. Managed Chromium blocks direct file navigation, so app browser checks use local HTTP; native Windows file launching and physical printing were not run. Rejected intermediate artifacts are not this release.
