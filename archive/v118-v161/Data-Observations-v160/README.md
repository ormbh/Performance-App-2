# Actionable data observations — v160

[Download app](../Performance-App-v160.zip) · [Policy](DATA-CHECKS-POLICY.md) · [Verification](../Saytara-Verification-v160.md)

Project end dates before start dates and numbers stored as text in numeric fields are now flagged. Month-only dates retain their precision. Numeric-text detection includes grouped amounts, percentages and Arabic digits. Original values and report calculations remain unchanged; approved v159 observations remain in place.

Screenshots and tests use the existing illustrative workbook. The user's uploaded production CSV is not included in this release.
