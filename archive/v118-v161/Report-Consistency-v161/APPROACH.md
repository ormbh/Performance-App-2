# Shared agenda and special-project reports — v161

The approved approach is one report composition and one set of presentation rules. **المستجدات التفصيلية** is exclusive to special projects. Actual report fields, status definitions, filters, metric denominators and source values keep their meaning.

## Contents, navigation and reading order

Both screens use one compact contents component. Its entries follow the report, omit empty sections and visibly identify any record count as a count. The report editor remains available beside the contents on wide screens and reflows on phones.

The report reading order is contents, executive summary charts and full compact definitions, records, special-project detailed updates where present, then report-level notes/recommendations. A PDF adds a full-bleed cover first. PDF contents displays final page references, with working internal links; special-project titles link to their detailed cards. Printed page numbering and copyright begin after the cover. Screen return controls do not appear as printed content.

## Table columns, records and numbering

Both reports use the same logical RTL sequence: **م → الموضوع/المشروع → الجهة المعنية → الحالة → نسبة الإنجاز where recorded → موعد الإنجاز**. Agenda has no invented percentage column. Project manager is omitted from the special-project main list and retained in meaningful project details.

Agenda categories follow approved agenda, emerging topics, then other/unclassified topics if present. Approved records retain their quarter grouping. This same category order is used in charts, contents and tables. The special-project main table follows ongoing then completed records, preserving the source status/end-date order inside those groups; its detail cards follow the same order. Every filtered report has continuous record numbering. Special-project details repeat the corresponding main-table number. On screen, their return link targets the exact row; PowerPoint returns to the containing table slide. PDF omits these screen return controls.

Headers, cell padding, status badges, long Arabic text wrapping, row separators, counts opposite headings and mobile field labels share the same design. Source sorting within the retained groups is preserved.

## Titles and front pages

Default titles are **مستجدات الأجندة السنوية {year}** and **مستجدات المشاريع الخاصة {year}**. Both use the same Arabic January-to-report-cutoff-month period format. The year and period follow the report date, never the download date. Deliberate custom titles and periods remain editable and are respected.

Each full-bleed cover centers its title, applicable selected entity and period together. No page number or copyright appears on the cover.

## Charts and definitions

Both chart types visibly identify **الإجمالي حسب الحالة**. Plain ready labels/counts are Teal, completed Green and late Red; marks and badges retain their approved contrasting inks. Use **مشاريع القيادة** consistently.

Legends keep all approved definitions and swatches while reducing heading size to 20px, status labels to 16px, and padding/gaps to 16px. Definition text remains 14px. PDF uses a 12pt legend heading and readable 10.5pt labels/definitions with reduced spacing. Recovered space enlarges the plots. Count proportions, scales and truthful small-segment label fitting remain intact. Charts, totals and full definitions stay together on the summary page for the tested normal/filtered scopes; unusually long source scopes may continue rather than clip.

Agenda retains vertical quarter columns and explicit quarter activation. Special projects retains horizontal sector bars and leadership/TEC cohorts, including blank leadership flags in TEC. Neither adds an unrequested exact-count print appendix. No Harvey balls are reintroduced.

## Additional information and empty results

Both reports place populated notes/recommendations at the end in stacked Paper cards, with right-aligned neutral headings and readable 16px text. The contents entry appears and disappears as these fields are edited. Empty optional fields remain hidden. Record-specific special-project updates stay in their original detail card.

A zero-result filter shows one clear report-level empty message. It does not show a contents list, blank chart, legend, dash-only summary card, invalid completion strip or repeated table empty state. Filters, reset and report settings remain available.

## Verification approach

Compare actual v160/v161 browser bundles using the unchanged illustrative workbook. Verify source-record equality, dashboard metrics, source date/snapshots and data observations before reviewing presentation. Exercise all, filtered, single-cohort and empty scopes; desktop, tablet and phone; contents links, project-return links, keyboard chart controls, continuous numbering, long Arabic text and edited report metadata.

Download actual native PDFs and check page geometry, cover/footer placement, chart/legend fit, record order and count, final contents page references, link destinations, text bounds and notes placement. Inspect native PowerPoint package structure, table/chart data, slide references and link relationships separately. A package check does not claim visual Office validation.
