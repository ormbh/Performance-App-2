## Offline interactive concept

Open **index.html** from the extracted folder. Fonts, images and illustrative records are included locally; no web connection is required. Try the sector, unit, concerned-entity and leadership filters, list search, status selection, pagination and project details.

Partial selections show the first selected name **+N**; unrestricted or full selections show **الكل**. The menu follows the approved app order. Other app pages are unavailable in this isolated concept.

The PDF button downloads the prepared review PDF for the unrestricted scope. It does not generate a new PDF from prototype filter selections. Applying the design to the app and its native offline exporter is a later step after review.

## Proposed changes

1. A familiar report header, four clear filters and summary first on screen; the cover remains in PDF.
2. A single summary card, readable sector names, exact counts and totals by status beneath the chart.
3. Wider project/entity columns, consistent status badges, and project details that distinguish recorded status from progress.
4. A full-page PDF cover and comfortable A4 landscape content pages.

All figures come from the illustrative workbook through the existing v154 model: **62 projects, including 24 leadership projects; 23 completed, 38 working and 1 other open**. Completion is **37.1%** overall and **50%** for the leadership subset. The displayed period is report metadata, not an additional date filter.

The fixture contains no populated project narratives. The separate narrative layout uses placeholders only; no project facts were invented. The phone table preserves all seven columns through horizontal scrolling.
