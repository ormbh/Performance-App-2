## Color and readability

جاهز للعرض uses Stone #ABA394; قيد المراجعة and قيد التطوير use Taupe #756B5F; منجز uses Green #01831E. Counts remain Charcoal. The legend uses Ink text with exact-color swatches, preserving readable names alongside the requested colored table labels.

The requested Stone table label has 2.42:1 contrast on Paper #FCFBFB, below normal-text contrast requirements. It is shown exactly for review; this is not an accessibility pass. Taupe (5.05:1), Green (4.77:1), and the Ink legend meet normal-text contrast. No new palette color has been substituted.
