# Agenda print revision — illustration only

This folder composes isolated A4 landscape previews. Production source remains unchanged.

- Physical page: 297 × 210mm.
- External inset: 10mm; footer inside a separate 8mm reserve.
- First-page header only: report title, selected entity if applicable, then reporting period.
- First-page chart overview is a single measured block.
- Continuation pages carry content and copyright/page footer only.
- Tables: 12pt Dubai Regular; headings 13.5pt Dubai Bold; section headings 16pt DIN.
- Quarter labels become section headings. Distinct source deadlines stay in rows.
- Source-notes appendix and its note cards are omitted from preview.
- All records and counts come from the illustrative workbook used in the preceding concept.

The source fixture is illustrative, not the user's operational workbook. Preview export layout can be reviewed before implementation in the offline app.
