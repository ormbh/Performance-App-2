# Continuous monthly report — v136

[Download the app](../Performance-App-v136.zip) · [Before / after](Continuous-Monthly-Before-After-v136.png) · [Current full layout](Continuous-Monthly-v136.png) · [Example PDF](ILLUSTRATIVE-Continuous-Monthly-v136.pdf)

The app now defaults to a continuous monthly PDF, with a wider 260mm canvas, 12mm margins and roomier card/table spacing. The actual sample is one page, approximately 260 × 602mm; its height follows the full selected content. The old preview was 210mm wide. Both sides use the same illustrative workbook and approved print font sizes, shown at the same native pixel scale.

Projects are left, executive portfolios right and followups span the full width below. All figures, statuses, notes and source scope are unchanged. The header appears once and copyright/page numbering once at the bottom. Use **إعدادات الطباعة → تنسيق التقرير** to switch between **PDF متصل — صفحة واحدة** and **A4 عمودي — للطباعة**. Choose Save as PDF in the browser dialog for continuous output.

This is illustrative source data, not the user's operational report. The source workbook, screenshots supplied by the user and QA test records are excluded from the app package. See [verification](../Saytara-Verification-v136.md), the independent review and final PDF binding for actual validation and limits. Other reports retain the approved A4 orientations and native Office templates.
