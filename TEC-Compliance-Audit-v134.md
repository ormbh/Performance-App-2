## Resolved material findings

The audit found effective cascade conflicts in primary hover/pressed, field hover/pressed and disabled controls; a PowerPoint loading label substitution; legacy HH ring/summary roles; old native chart palettes; Dubai Bold plot quantities; checks result/severity text at 15px/600; and mobile first source cells at 600. The root implementation corrected these narrowly, preserving source scope, counts, categories, scales and row membership. The latest targeted checks verify Dubai 16px Regular (400) first source cells/results, DIN LT Regular (400) plot annotations and the HH SVG card radius measured at 18 CSS px after its viewBox scaling.
