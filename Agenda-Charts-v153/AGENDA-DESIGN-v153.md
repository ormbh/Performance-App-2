# Approved agenda quarter chart — v153

This implements the revised review concept approved on 13 October 2026. The application uses its actual filtered report model; it does not use the fixed screenshot values in the review illustration.

- One vertical stacked column per active quarter, with the topic count above and the quarter label below.
- One common count scale across visible categories, starting at zero, using whole-number ticks and an upper bound derived from the highest quarter count. Counts are not normalized by category total.
- Approved agenda physically right; emerging topics left. A populated additional source category remains available. Empty categories hide, and a single remaining category uses the available width.
- Preserve source status mapping, active-quarter union/order, latest-date and carryover rules, explicit undated topics, and all eligible records.
- No chart percentages or selected-quarter ratio summary lines. Zero counts remain dashes.
- Original definition legend under the chart, including the late definition. Completed and late status labels/counts retain Green and Red; other status text remains Ink.
- Exact quarter breakdowns remain available with keyboard/mouse interaction and a count table on screen.
- The offline PDF uses native chart shapes and text. Cover, title/entity/period, footer numbering and detail-table rules remain as approved. Charts and definitions stay together on the first content page.

The app’s data matching, performance definitions and workbook remain unchanged. No redesign of council, HH or monthly charts is included.
